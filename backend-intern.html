Backend Intern

We are looking for a curious and skilled Backend Engineering Intern to join our team. You will work on building and enhancing features through RESTful APIs, while gaining hands-on experience with cloud infrastructure and databases

Responsibilities

  • Develop and maintain backend services using Python.
  • Work with cloud infrastructure and database systems.
  • Create and enhance RESTful APIs.
  • Collaborate with team members to implement new features
  • Learn and apply DevOps practices

Requirements

  • Strong Python programming skills
  • Interest in DevOps and cloud infrastructure
  • Eagerness to understand business context
  • Experience with SQL and database concepts
  • Willingness to learn TypeScript/Node.js as needed

How to Apply

  1. Choose a project you have contributed to (could be open source, academic, or personal).
  2. Write one page about the project, focusing on:
    • Project overview
    • Your specific contributions
    • Technical challenges faced and overcome
    • Impact of your work
  3. Email prasanna@mycroft.in with:
    • Subject line: “Backend Internship Application”
    • Your one-page write-up
    • Link to relevant code repository or pull request
