Machine Learning Intern

We are looking for a Machine Learning Intern with strong analytical skills to work on end-to-end ML solutions. You will tackle real business challenges while implementing practical machine learning solutions from conception to deployment.

Responsibilities

  • Analyze business problems and conceive ML solutions.
  • Develop end-to-end ML implementations.
  • Work with data extraction and preparation.
  • Deploy models in production environments.
  • Deploy models in production environments.

Requirements

  • Strong foundation in statistics and classical ML techniques.
  • Experience with Python and R for data analysis.
  • Understanding of fundamental ML algorithms (boosted trees, linear regression, etc.).
  • Interest in MLOps and deployment practices.
  • Tidymodels experience is a plus

How to Apply

  1. Choose a project you have contributed to (could be open source, academic, or personal).
  2. Write one page about the project, focusing on:
    • Project overview
    • Your specific contributions
    • Technical challenges faced and overcome
    • Impact of your work
  3. Email prasanna@mycroft.in with:
    • Subject line: “Machine Learning Internship Application”
    • Your one-page write-up
    • Link to relevant code repository or pull request
